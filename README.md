# ᴇʟɪɴᴀ ꭙ ᴍᴜsɪᴄ˼ ♪

Telegram voice-chat music bot. Features: **music** + **welcome message**. Nothing else.

**Music:** /play /vplay /pause /resume /skip /end /queue /loop /np /autoplay /favs /playfav
**Welcome:** sent automatically to new members (admins: /welcome, /setwelcome, /resetwelcome, /welcomecard)

Setup: copy `env.example` to `.env`, fill it in, `pip install -r requirements.txt`, `python3 main.py`.
Add the bot AND the assistant account (STRING_SESSION) to your group, then start a voice chat.
